# SDCI Lab 02 — Remote Access VPN (GCP)

**Cisco SDCI 300-745 Domain**: Internet Edge security & VPN connectivity

## Overview

Deploy an HA VPN Gateway connecting a hub VPC (corporate) to an on-prem VPC (remote site) using BGP dynamic routing. Verify cross-VPC connectivity over the encrypted IPsec tunnel.
